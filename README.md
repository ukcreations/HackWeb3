🌐 Decentralized Blog DApp

A full-stack Web3 Blogging Application where users can create, store, and view blog posts in a decentralized way.
Blog data (title + content) is stored on IPFS, while post metadata (author, IPFS hash, timestamp) is stored on-chain using Solidity.

🚀 Features

📝 Create and upload posts to IPFS

🔗 Save post metadata (title + hash) on Ethereum

👨‍💻 Display posts in a React frontend

💰 Learn contract ↔ frontend integration using Ethers.js

📡 Event-based real-time post updates

🧩 Tech Stack
Layer	Tool

)
